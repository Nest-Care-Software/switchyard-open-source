# V1 prioritises safe execution over resilience and reporting

Switchyard V1 proves one safe Azure runner generation with a fixed 45-minute
lifetime, Blacksmith fallback, complete reconciliation, and trusted production
deployment support. Automatic Azure replacement, 90-minute allocations, live
D1 reporting, scheduled statistics, diagnostic uploads, hosted recovery, and
GitHub incident automation move to V2 because they add substantial integration
and failure handling without strengthening the minimum billing, identity, or
cleanup guarantees needed for the pilot.
